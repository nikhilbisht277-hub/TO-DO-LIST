# 📝 My To-Do List

A modern, responsive, and user-friendly To-Do List web application built using **HTML, CSS, and JavaScript**.

This application helps users manage their daily tasks efficiently. Users can add new tasks, mark them as completed, delete unwanted tasks, and filter tasks based on their status.

## ✨ Features

* ➕ Add new tasks
* ⌨️ Add tasks using the Enter key
* ✅ Mark tasks as completed or pending
* 🗑️ Delete tasks
* 🔍 Filter tasks by All, Pending, and Completed
* 📊 Display Total, Completed, and Pending task counters
* 💾 Local Storage support to save tasks after page refresh
* 📱 Fully responsive design for mobile, tablet, and desktop
* 🎨 Modern and clean user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage
* Font Awesome Icons

## 🚀 How to Use

1. Clone or download this repository.
2. Open the project folder.
3. Run the `index.html` file in your browser.
4. Start adding and managing your tasks!
